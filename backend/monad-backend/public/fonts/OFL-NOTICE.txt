Vendored webfonts for the management interface (IP-157, Phase 8)
===============================================================

These files are served by this application from `public/fonts/` and are never
fetched from a third-party host. The admin may be published on a public vhost,
and a font request to Google Fonts would tell that host every operator's IP
address and page load. The files are copies of the subsets already vendored by
the public site (`monad_knowledge/web/static/dist/assets/`, from the
`@fontsource-variable/ibm-plex-sans`, `@fontsource/ibm-plex-mono` and
`@fontsource-variable/literata` packages); only the latin and latin-ext subsets
are copied, which is what this interface's copy uses.
